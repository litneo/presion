# Mi Presión Pro v4 — Presión + Azúcar

Añade un módulo independiente para glucosa/azúcar en sangre:
- Botón grande "REGISTRAR AZÚCAR".
- Flujo guiado para adulto mayor.
- Paciente y persona que registra.
- Valor en mg/dL.
- Momento: ayunas, antes de comer, después de comer u otro.
- Fecha y hora automáticas.
- Pantalla de confirmación.
- Historial independiente de azúcar.
- Filtros por fecha.
- Última medición de azúcar en el dashboard.
- Respaldo/importación incluye presión y glucosa.
- IndexedDB local y PWA offline.

La aplicación solo registra información y no realiza diagnóstico médico.
